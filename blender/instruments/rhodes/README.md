# Fender Rhodes

Keith Godchaux's electric piano, set beside the grand for Winterland, October
1974. It's modelled on the Grateful Dead's own Rhodes, a "Seventy-Three"
Stage Piano, serial 27763, which Sotheby's sold in 2021 as property of
Grateful Dead Productions (lot 53).

Keith added a Rhodes in mid-1973 and kept one through 1976. Which model he
played at Winterland isn't documented:
- Equipboard shows a Mark I Eighty-Eight at the Orpheum rehearsals in June 1976.
- Sotheby's Rhodes, the band's own, is a 73 and undated.

The 73 was chosen, and the model is **unconfirmed for October 1974**.

## Measured on the straight-on photograph

- **Scale:** Sotheby's 45" width is 1,775 px of the base's front, so 39.4 px/in.
- **Keys:** 73, counted: 30 sharps in twelve alternating groups of three and two, starting F♯ G♯ A♯, so E to E. Sotheby's "75 keys" can't be an E-to-E keyboard.
- **White keys:** 0.92" each (43 across 1,559 px); a standard key is 0.925".
- **Rail and lid:** 41" wide, between the end walls.
- **Cheek blocks:** 1.8".
- **Base front:** 2.5" (100 px).
- **Lid front:** about 2.7" (107 px).
- **Overall:** 23" deep and 8" high (Sotheby's).
